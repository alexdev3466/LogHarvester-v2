# LogHarvester-v2
A lightweight, multi-threaded utility for parsing and extracting credentials from IMAP server logs and malware stealer outputs (e.g., RedLine, Raccoon, Vidar). Designed for security researchers and penetration testers to automate credential validation and combo list generation.                                                                                                                               Features include:                                                                                                                         IMAP Protocol Support: Direct validation of credentials against live IMAP servers (SSL/TLS).  
Log Parsing: Extracts credentials from stealer logs (supports common formats like , , )..txt.json.cookie.
Combo Generation: Converts parsed data into formatted combo lists (email:password) for further testing.
